# Yashwanth Reddy Vasireddy | AI, ML & Data Science

Sleek, high-performance Next.js web personal portfolio.

🔗 **Live Site:** [vasireddy.dev](https://vasireddy.dev)

## ⚡ Tech Stack
This application is built with a focus on speed, fluid animations, and zero-maintenance infrastructure.
* **Framework:** Next.js (App Router)
* **Library:** React.js
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **Deployment:** Vercel (Edge Network)

## 🚀 Key Features
* **Custom Framer Motion Animations:** Features dynamic, physics-based hover states and scroll-triggered viewport animations.
* **Component-Driven Architecture:** Modular React components for scalable data arrays (Experience Timeline, Project Archive).
* **Next.js Image Optimization:** Automatic WebP conversion and lazy-loading for heavy asset project cards.

## 💻 Local Development
To run this project locally on your machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/Yashwanth-23/portfolio.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
